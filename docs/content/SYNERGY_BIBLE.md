# SYNERGY_BIBLE.md

# Junkriot - Référence Officielle des Synergies v2.0

## Règle Fondamentale

Une synergie s'ajoute toujours au comportement normal des tours.
Elle ne remplace jamais leur fonctionnement de base.

Objectif :
- Visible immédiatement
- Compréhensible sans lire une description
- Change le placement des tours
- Crée un nouveau comportement

# S Tier

## #03 Mur Tesla
Sprogg + Sprogg

Effet :
Arc électrique permanent entre les deux tours.
Dégâts continus aux ennemis traversant la liaison.

Visuel :
Line2D bleu + étincelles.

## #04 Brouillard Toxique
Frostwick + Smogsworth

Effet :
Les ennemis ralentis subissent un poison x3.

Visuel :
Nuage turquoise.

## #08 Laser Guide
Vega + Grumbolt

Effet :
Les obus de Grumbolt suivent les cibles marquées par Vega.
+50% dégâts.

Visuel :
Laser rouge permanent.
Traînée rouge sur les obus.

## #11 Point d'Effondrement
Mama Cog + Anchor

Effet :
Les ennemis sont attirés vers le centre de l'aura.

Visuel :
Vortex.
Trajectoires courbes.

## #12 Verrouillage
Krutz + Vega

Effet :
Chaque tir de Vega déclenche une salve complète de Krutz.

Visuel :
Projectiles rouges spéciaux.

# Règles de Feedback

Connexion :
- Line2D

Projectile modifié :
- Changement de couleur

Cible désignée :
- Rune ou icône flottante

Zone amplifiée :
- Couleur et taille modifiées

Aura :
- Tween de taille et luminosité

Comportement nouveau :
- Mouvement ou trajectoire différente
