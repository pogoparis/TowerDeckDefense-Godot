# Deck System

## Règles Officielles

- Main normale : 3 cartes
- Main maximale : 4 cartes
- Les cartes Tour sont brûlées après utilisation
- Pas de défausse
- Pas de reshuffle

## Fin de vague

Le joueur repioche jusqu'à 3 cartes.

## Rewards

### Carte Tour
Ajoutée directement dans la main.

### Bonus
Appliqué immédiatement.

### Relique
Activée immédiatement et reste active toute la run.

## Philosophie

Chaque carte est une ressource limitée.
Chaque placement compte.
