# Junkriot - Gameplay Bible

## Core Loop
1. Préparation
2. Pioche jusqu'à 3 cartes
3. Placement des tours
4. Lancement de la vague
5. Récompense
6. Vague suivante

## Règles Deck
- Main normale : 3 cartes
- Main maximale : 4 cartes
- Une carte Tour jouée est brûlée définitivement
- Pas de défausse
- Pas de reshuffle

## Récompenses
### Carte Tour
Ajoutée à la main

### Bonus
Appliqué immédiatement

### Relique
Appliquée immédiatement et reste active toute la run
