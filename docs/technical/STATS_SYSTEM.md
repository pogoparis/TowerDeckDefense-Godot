# Stats System

## Ordre officiel de calcul

1. Statistiques de base
2. Bonus de run
3. Multiplicateurs de synergie
4. Feedback visuel

Formule :

(Base + Bonus Run) x Multiplicateurs

## Exemple

Base Range = 120
Bonus Range = +50
Synergie = +30%

(120 + 50) x 1.30 = 221

## Bug historique

Les synergies ne doivent jamais écraser les bonus de run.
